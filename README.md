# ralph-lecturer

A Ralph Wiggum-powered tool that turns any topic into a narrated, animated video lecture — MIT recitation style for math/CS, screencast style for CLI tools.

## What it builds

```
python main.py "how to use grep"
# → output/how-to-use-grep/final.mp4
```

A fully rendered MP4 with:
- Animated visuals (Remotion for CLI topics, Manim for math/CS)
- AI-generated MIT recitation-style narration script
- Natural-sounding voice via edge-tts
- Burned-in subtitles

## Prerequisites

**System**
- Python 3.10+
- Node 18+ (for Remotion)
- ffmpeg
- texlive-full (only needed for Manim/math topics)

**Python packages**
```bash
pip install manim edge-tts anthropic mutagen --break-system-packages
```

**Remotion**
```bash
cd remotion-src && npm install && cd ..
```

**Environment**
```bash
export ANTHROPIC_API_KEY=sk-...
```

## Usage

```bash
python main.py "how to use grep"
python main.py "Fourier Transform"
python main.py "how to use sed" --voice en-GB-SoniaNeural
python main.py "Bayes Theorem" --random-voice
```

## Running with Ralph (autonomous build)

This repo is scaffolded for the Ralph Wiggum technique — a bash loop that runs Claude Code autonomously to implement the full pipeline from specs.

**Requires:** Claude Code CLI (`npm install -g @anthropic-ai/claude-code`)

```bash
# Step 1: Generate implementation plan
./loop.sh plan

# Step 2: Let Ralph build (runs until done or Ctrl+C)
./loop.sh

# Step 3: Cap iterations if you want to check progress
./loop.sh 10
```

Ralph reads the specs in `specs/` and builds the full pipeline stage by stage, committing after each working increment.

## Project structure

```
main.py                        # CLI entry point (built by Ralph)
loop.sh                        # Ralph loop script
PROMPT_plan.md                 # Ralph planning prompt
PROMPT_build.md                # Ralph build prompt
AGENTS.md                      # How to build/test/run (Ralph reads this)
IMPLEMENTATION_PLAN.md         # Generated by Ralph, tracks progress

specs/
  01-cli.md                    # CLI interface spec
  02-script-generation.md      # Claude API script generation spec
  03a-animation-remotion.md    # Remotion renderer (CLI/tutorial topics)
  03b-animation-manim.md       # Manim renderer (math/academic topics)
  04-tts.md                    # edge-tts audio + word boundaries
  05-subtitles.md              # SRT subtitle generation
  06-composition.md            # ffmpeg composition

pipeline/                      # Built by Ralph
  script.py
  animation.py
  tts.py
  subtitles.py
  composition.py
  utils.py

remotion-src/                  # Built by Ralph
  Root.tsx
  compositions/
  components/

output/
  {topic-slug}/
    script.json
    subtitles.srt
    scenes/
    audio/
    final.mp4                  # ← your video
```

## Topic routing

The script generator classifies each topic and sets the renderer:

| Topic type | Renderer | Example |
|---|---|---|
| CLI tools, shell, developer workflows | Remotion | "how to use grep" |
| Math, physics, formal CS | Manim | "Fourier Transform" |
